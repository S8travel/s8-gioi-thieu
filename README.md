# S8 Travel — trang giới thiệu đối tác

Trang tĩnh, deploy Vercel. **Không sửa tay `index.html`** — file này do
`clean-code-hub/_S8_WEB_ANH/_build-v11.py` sinh ra (khung ở `_v11-shell.html`).

## Đổi ảnh
- Bỏ ảnh vào đúng thư mục + đúng tên theo `HUONG-DAN-THAY-ANH.txt`, nhấn đúp
  `_GHEP-TRANG.bat` bên `clean-code-hub/_S8_WEB_ANH/`, rồi `_DAY-LEN-WEB.bat` để đẩy lên.
- Khách sạn / nhà hàng: trang đọc ảnh trực tiếp từ hệ thống CRM khi chạy trên web;
  ảnh trong `anh/` chỉ dùng khi hệ thống chưa có ảnh cho cơ sở đó.

## Nguồn ảnh
- `anh/slides/`, cảnh điểm: Wikimedia Commons, giấy phép CC / public domain — trang
  hiện dòng ghi công tác giả + giấy phép dưới mỗi ảnh (điều kiện của giấy phép).
- `anh/venues/`: ảnh/logo lấy từ website hoặc Facebook chính thức của đối tác.
- `anh/xe/`: ảnh đội xe, đã gom theo cỡ xe, không nêu tên nhà xe.
